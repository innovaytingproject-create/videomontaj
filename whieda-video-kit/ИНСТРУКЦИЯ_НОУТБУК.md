# Монтаж на ноутбуке через Claude Code — пошагово

## Шаг 1. Установить программы (один раз)

Можно поставить всё самой (ниже) или на шаге 4 попросить Claude: «установи всё, что нужно».

**Mac**
1. Claude Code — в «Терминале»: `curl -fsSL https://claude.ai/install.sh | bash`
2. Homebrew (если нет) — команда с сайта https://brew.sh
3. Остальное одной строкой: `brew install node python ffmpeg`

**Windows**
1. Claude Code — в PowerShell: `irm https://claude.ai/install.ps1 | iex`
2. Остальное в PowerShell:
   `winget install OpenJS.NodeJS.LTS Python.Python.3.12 Gyan.FFmpeg`
3. Закройте и заново откройте окно терминала, чтобы команды подхватились.

Проверка: `node -v`, `python3 --version` (на Windows `python --version`), `ffmpeg -version` — каждая должна показать номер версии.

## Шаг 2. Скачать набор

Архив `whieda-video-kit.zip` — из чата или с GitHub
(ветка `gotovye-video` → папка `МАТЕРИАЛЫ_ДЛЯ_МОНТАЖА`).
Распакуйте в `Документы` → получится папка `Документы/whieda-video-kit`.

## Шаг 3. Открыть терминал в этой папке

- **Mac:** откройте «Терминал» и наберите `cd ~/Documents/whieda-video-kit`
- **Windows:** откройте папку в Проводнике → правый клик по пустому месту →
  «Открыть в терминале».

Наберите `claude` и нажмите Enter. При первом запуске войдите в свой аккаунт Claude.

## Шаг 4. Первая настройка (один раз)

Напишите Claude:

> Прочитай CLAUDE.md. Проверь, что всё установлено (раздел 0), установи недостающее
> и запусти самотест.

Он будет спрашивать разрешения на команды. Для `python`, `npx`, `ffmpeg`, `pip`
выбирайте «Yes, and don't ask again» — тогда дальше спрашивать почти не будет.
Дождитесь строки **SELFTEST OK**.

## Шаг 5. Монтаж нового видео

1. Видео загрузите в Google Drive → «Поделиться» → «Все, у кого есть ссылка».
2. Напишите Claude, например:

> Новое видео: https://drive.google.com/file/d/…/view
> Это про продукт FOHERB. Смонтируй в нашем стиле WHIEDA, сначала 15 секунд.

3. Он покажет, где лежит пример: `projects/<название>/out/<название>-15s.mp4`.
   Откройте и посмотрите.
4. Правки пишите обычными словами:
   - «субтитр на 5-й секунде: правильно *Assalomu alaykum*»
   - «карточку на 40-й секунде убери», «логотип показывай дольше»
   - «голос громче», «музыку тише»
5. Когда нравится: «Делай полное видео».
6. Готовое: `projects/<название>/out/<название>.mp4` — это для Instagram.
   Для Телеграма: «сожми для Телеграма» → файл `…-small.mp4`.

Чтобы открыть папку с результатом: «открой папку с готовым видео».

## Полезно знать

- **Ноутбук на зарядке** и не уходит в сон, пока идёт рендер
  (Mac: можно написать Claude «запусти рендер через caffeinate»).
- Время: расшифровка речи 5–15 мин, рендер 1,5-минутного ролика 10–25 мин.
- Место на диске: около 10 ГБ свободно (модель речи ~3 ГБ скачивается один раз,
  промежуточные файлы ~1 ГБ на ролик). Старые проекты можно удалять из `projects/`.
- Каждый раз открывайте `claude` **именно в папке whieda-video-kit**, иначе он не
  увидит инструкцию.
- Новая тема без связи со старой — команда `/clear`, чтобы начать чистый разговор
  (инструкция подхватится заново).

## Если что-то не так

| Проблема | Что написать Claude |
|---|---|
| «command not found: claude» | закройте и откройте терминал; на Mac проверьте шаг 1 |
| Видео не скачивается с Drive | проверьте доступ «Все, у кого есть ссылка», или скачайте вручную и напишите «вот файл: <перетащите файл в терминал>» |
| Ошибка при рендере | «рендер упал, разберись и почини» |
| Субтитры с ошибками | «вычитай все субтитры ещё раз и покажи список» |
| Не нравится стиль | опишите словами и попросите сначала 15 секунд |
