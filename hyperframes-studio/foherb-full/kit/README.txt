FOHERB — НАБОР ДЛЯ САМОСТОЯТЕЛЬНОГО МОНТАЖА
============================================

Всё, из чего собран ролик, отдельными файлами. Кладёте свой исходник
на таймлайн — и собираете/меняете как хотите.

ПАПКА overlays/ — ГРАФИЧЕСКИЕ ВСТАВКИ (1080x1920, 30 fps)
---------------------------------------------------------
Каждая вставка: анимация появления, дальше кадр статичный — тяните клип
по длине сколько нужно, исчезновение делайте своим фейдом/обрезкой.

Зелёный фон = хромакей. В CapCut: наложение -> клип -> «Вырезать фон» /
«Хромакей», пипеткой в зелёный, интенсивность ~80%.

Файл                      Где стоит в моём монтаже (тайминг исходника)
intro-card.mp4            00:00–00:02.4 (обложка, фон свой — без кея)
banner.mp4                00:05.4 iOS-уведомление «yangi xarid»

stat-1-10.mp4             02:24.2 счётчик «1 = 10»

Там же .webm — те же вставки с НАСТОЯЩЕЙ прозрачностью (без кея).
Работают в CapCut Desktop, Premiere, DaVinci. Если ваш редактор их не
берёт — используйте .mp4 с хромакеем.

captions_uz.srt — СУБТИТРЫ (узбекский)
--------------------------------------
Тайминги под НЕрезаный исходник. В CapCut: Текст -> Импорт субтитров
(или «Авто-субтитры» замените этим файлом). Стиль из ролика:
шрифт Inter Display SemiBold (бесплатный: rsms.me/inter или Google Fonts
«Inter», включить оптический размер Display), белый, тень чёрная мягкая,
выделенные слова — голубым #0A7AFF.

foherb-cool-grade.cube — ПОКРАСКА (LUT)
---------------------------------------
Тот самый бело-голубой грейд. В CapCut: Коррекция -> LUT -> импорт .cube,
применить к исходнику, интенсивность 100%.
