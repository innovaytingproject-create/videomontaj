# Промты для Claude Code на компьютере

Все наработки по монтажу лежат на GitHub:
репозиторий `innovaytingproject-create/videomontaj`, ветка
`claude/video-editing-cloud-credits-nvj5uh`, папка `whieda-video-kit`.

- `CLAUDE.md` — главная инструкция (Claude читает её сам).
- `docs/ВСЁ_О_МОНТАЖЕ.md` — вся база знаний одним файлом: стиль, правила клиента, приёмы,
  журнал правок, все ролики со ссылками на исходники.
- `archive/` — монтажные файлы каждого ролика (субтитры, тайминги, нарезка).
- `assets/` — шрифты, логотип, иконки, 153 стикера, музыка, звуки.
- `pipeline/` — скрипты, которые собирают видео.

Готовые ролики — ветка `gotovye-video`, папка `ГОТОВЫЕ_ВИДЕО`.

---

## Промт 1. Первая настройка (один раз)

Откройте терминал в любой папке, запустите `claude` и вставьте:

```
Скачай мой набор для монтажа с GitHub и подготовь компьютер к работе.

1. Склонируй репозиторий:
   git clone --depth 1 -b claude/video-editing-cloud-credits-nvj5uh https://github.com/innovaytingproject-create/videomontaj ~/Documents/videomontaj
   (если папка уже есть — зайди в неё и сделай git pull). Если GitHub просит вход — помоги мне войти (gh auth login).
2. Перейди в ~/Documents/videomontaj/whieda-video-kit и прочитай CLAUDE.md и docs/ВСЁ_О_МОНТАЖЕ.md.
3. Проверь и установи всё нужное сам (раздел 0 в CLAUDE.md): Node.js 22+, Python 3.10+, ffmpeg,
   пакеты из requirements.txt, браузер HyperFrames (npx --yes hyperframes@0.8.137 browser ensure).
4. Запусти python3 pipeline/selftest.py и чини, пока не будет SELFTEST OK.
5. Коротко напиши мне по-русски, что установлено и что всё готово.
```

После этого всегда открывайте `claude` **в папке**
`~/Documents/videomontaj/whieda-video-kit` — тогда он сразу знает весь стиль.

## Промт 2. Новый ролик

```
Прочитай CLAUDE.md и docs/ВСЁ_О_МОНТАЖЕ.md. Работай автономно, без вопросов.
Смонтируй ролик по этим ссылкам Google Drive (если частей несколько — это один ролик, склей по порядку):
Часть 1: <ссылка>
Часть 2: <ссылка>

Сделай динамично: убери паузы между фразами (проходы и показ товара не режь), наезды и отъезды,
мягкие переходы, иконки и стикеры по смыслу, белые карточки, саунд-дизайн, логотип WHIEDA, когда о нём говорят.
Сам вычитай узбекские субтитры, проверь кадры, длительность и громкость, исправь ошибки.
Когда готово: сделай сжатую версию для Телеграма, открой папку с результатом,
коротко напиши по-русски, что сделано и что мне стоит проверить.
```

Если это **личный блог Ферузы** — добавьте строку: «Это блог Ферузы, без логотипа WHIEDA».
Если нужно ещё и **отдельный ролик из одной части** — так и напишите: «часть 6 — и в общий
ролик, и отдельным роликом».

## Промт 3. Правки

Пишите обычными словами в том же окне, например:
```
Поправь ролик <название>: на 0:35 субтитр должен быть «...»; вспышек меньше;
не режь место, где она идёт и говорит; добавь иконку на «direktga yozing»;
звук прибора на 1:15 мешает — убери. Пересобери и проверь кадры.
```

## Промт 4. Выложить готовые ролики на GitHub

```
Выложи готовые ролики в полном качестве на GitHub, как описано в docs/ВСЁ_О_МОНТАЖЕ.md, раздел 9:
ветка gotovye-video, папка ГОТОВЫЕ_ВИДЕО/<номер>_<название>_<длина>, файлы больше 90 МБ разрежь на части.
Монтажные файлы проекта (project.json, work/cut.py, work/keep.json, work/words.json)
скопируй в whieda-video-kit/archive/<проект>/ и закоммить в рабочую ветку.
```

## Промт 5. Скачать готовые видео на компьютер

```
Скачай готовые видео из https://github.com/innovaytingproject-create/videomontaj, ветка gotovye-video.
Если папки ~/Desktop/gotovye-video нет — git clone --depth 1 --single-branch -b gotovye-video <адрес> ~/Desktop/gotovye-video,
иначе зайди в неё и сделай git pull. Склей части .part01/.part02 в целые .mp4
(СОБРАТЬ_ВИДЕО_Mac_Linux.sh или СОБРАТЬ_ВИДЕО_Windows.bat), проверь, что видео открываются,
удали .partXX и открой папку ГОТОВЫЕ_ВИДЕО.
```

## Полезно знать

- Ссылки Google Drive должны быть открыты «Все, у кого есть ссылка».
- Первая расшифровка речи скачивает модель (~3 ГБ) один раз.
- Рендер 1,5-минутного ролика — 10–25 минут; ноутбук на зарядке, без сна.
- Нужно ~10 ГБ свободного места. Старые проекты в `projects/` можно удалять:
  всё нужное для переделки лежит в `archive/` и в Google Drive.
