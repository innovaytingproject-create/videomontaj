# WHIEDA Video Kit — автономный монтаж Reels

Это всё, что получилось и было утверждено при монтаже роликов для Ферузы / WHIEDA:
стиль, шрифты, логотип, иконки, звуки, музыка, цвет, настройки голоса и скрипты,
которые собирают видео автоматически. Claude Code на вашем компьютере прочитает
`CLAUDE.md` и будет монтировать сам, без этого чата.

## Как запустить (один раз)

0. Подробная пошаговая инструкция для ноутбука (Mac и Windows) — `ИНСТРУКЦИЯ_НОУТБУК.md`.
1. Распакуйте архив в удобную папку, например `Документы/whieda-video-kit`.
2. Откройте терминал **в этой папке** и запустите `claude`.
3. Напишите ему:

   > Прочитай CLAUDE.md. Проверь, что всё установлено (раздел 0), и запусти самотест.

   Он сам проверит Node.js, ffmpeg, Python и поставит недостающее (спросит разрешение).

## Как заказывать монтаж

Просто пишите в том же терминале, например:

> Вот новое видео: https://drive.google.com/file/d/…/view
> Смонтируй в нашем стиле. Сначала 15 секунд на согласование.

Дальше он: скачает видео → покрасит и почистит голос → расшифрует узбекскую речь →
расставит субтитры, логотипы, карточки, переходы, звуки → покажет 15 секунд →
после вашего «да» сделает полное видео.

Готовые ролики лежат в `projects/<название>/out/`.
- `<название>.mp4` — полное качество для Instagram.
- Попросите «сожми для Телеграма» — сделает `<название>-small.mp4` (до 28 МБ).

Правки пишите обычными словами: «подними субтитры», «карточку на 40-й секунде
убери», «логотип показывай дольше» — он поправит `project.json` и пересоберёт.

## Важно

- Ссылка Google Drive должна быть открыта «Все, у кого есть ссылка».
- Первая расшифровка речи скачает модель (~3 ГБ) — один раз.
- Рендер 1,5-минутного видео на ноутбуке — примерно 10–25 минут.
- Официальный логотип WHIEDA в PNG/SVG стоит запросить у компании и положить в
  `assets/logo/whieda-emblem.png` (сейчас — восстановленный из брендбука).

## Что внутри

| Папка | Что там |
|---|---|
| `CLAUDE.md` | Главная инструкция для Claude Code: стиль, правила клиента, порядок работы |
| `pipeline/` | Скрипты: скачать, подготовить, расшифровать, собрать, смикшировать, сжать |
| `template/` | Утверждённый дизайн (CSS), GSAP и шрифты для рендера |
| `assets/` | Логотип, шрифты, иконки (+ каталог), стикеры, звуки, музыка, LUT для CapCut |
| `examples/whieda-tour/` | Настройки утверждённого «Тура по офису» — образец |
| `docs/` | Полное ТЗ и история правок, брендбуки, кадры-эталоны, субтитры прошлых роликов |
| `projects/` | Сюда складываются новые проекты (создаётся автоматически) |
